# ایران | بازی داستانی آفلاین

«ایران» یک بازی داستانی و انتخاب‌محور برای اندروید است. بازیکن در ۸ مرحله شرایط تولد و زندگی خود را انتخاب می‌کند و برای انتخاب‌های غیرقابل‌عبور وارد بازی‌های فرعی اختصاصی می‌شود.

## ویژگی‌ها

- کاملاً آفلاین؛ بدون ساخت حساب، سرور یا دسترسی اینترنت
- یک ذخیرهٔ مستقل روی همان گوشی در مسیر محلی برنامه
- ۸ مرحله و ۳۰ بازی فرعی با تعامل‌های لمسی، کشیدنی، منطقی، حافظه‌ای و مدیریتی
- رویدادهای جانبی ساختگی و امن؛ بدون تراکنش یا دریافت اطلاعات حساس واقعی
- تنظیمات موسیقی، افکت، حجم صدا، سرعت انیمیشن، سختی، جلوه‌ها، لرزش و رنگ محیط
- رابط فارسی، تمام‌صفحه و عمودی
- صفحهٔ پایانی تصویری

## ساخت APK اندروید

فایل گردش‌کار `.github/workflows/android-apk.yml` با تغییر فایل بازی، آیکن، منابع اصلی یا خود گردش‌کار اجرا می‌شود. خروجی APK و بستهٔ سورس در بخش Artifacts همان اجرای GitHub Actions قرار می‌گیرند.

## بررسی فنی

ساخت موفق به‌تنهایی تضمین‌کنندهٔ اجرای بی‌نقص روی تمام گوشی‌ها نیست. گردش‌کار، واردسازی پروژه، خطاهای اسکریپت، اجرای آزمایشی headless و خروجی اندروید را بررسی می‌کند. آزمون نهایی روی دستگاه واقعی نیز لازم است.
